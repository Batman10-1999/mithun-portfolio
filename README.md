# Mithun S — Interactive 3D Portfolio

An immersive 3D portfolio designed as an interactive digital universe.
Explore my identity, skills, education, projects, experience and achievements.
Navigate through a planetary interface instead of a traditional portfolio layout.
Earth serves as the central hub for discovering different worlds.
Mars showcases my projects across AI, software, civic technology and networking.
Mercury presents my technical skills across data, programming and AI/ML.
Uranus connects to my live GitHub activity and development journey.
The experience includes cinematic transitions, spacecraft, travel trails and hidden discoveries.
Built with React, TypeScript, Three.js, React Three Fiber, Drei and modern web technologies.
